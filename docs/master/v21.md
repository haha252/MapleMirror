# Master 数据库版本 21

## 结构变化

- `node_tasks` 增加 `attempt_id`，供 control.v2 用领域 attempt 身份替代全局消息序号。
- 新增 `asset_piece_manifests`，保存资产的 authoritative piece manifest、整文件摘要、piece layout 与紧凑 SHA-256 hash blob。
- `piece_count` 硬限制为 8192。
- 新增 `node_inventory_v2_segments` receipt 表，以 `(node_id, revision, segment)` 持久化 v2 inventory segment 幂等边界；相同 segment 重放可安全 ACK，不同 payload 复用同一 identity 会被拒绝。

## 升级器

- `internal/storage/upgrades/master.V20ToV21`。
- 对历史最小化测试库会先检查相关表是否存在，升级保持幂等。

## 验证方式

- `go test ./internal/storage`
- `go test ./internal/master/control`
