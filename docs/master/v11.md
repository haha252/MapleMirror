# 主节点数据库版本 11

v11 为公开统计页、管理总览和节点流量展示增加小型状态表，避免高频读取时反复扫描历史统计表。

## 结构变化

- 新增 `public_stat_totals`，保存全站累计访问、下载、Web/API 下载、开始传输和发送字节。
- 新增 `daily_public_stats`，保存每日全站趋势汇总。
- 新增 `asset_stat_totals`，保存资产累计下载、Web/API 下载、开始传输和发送字节。
- 新增 `node_traffic_totals`，保存节点累计发送字节。
- 新增 `idx_asset_stat_totals_downloads`，用于热门资源排行。
- 新增 `idx_traffic_event_dedupe_accounted` 和 `idx_traffic_event_dedupe_authorization_accounted`，用于管理面板流量事件分页。

## 升级行为

- `master.V10ToV11` 在事务内创建状态表和索引。
- 从 `daily_site_stats`、`daily_project_stats`、`daily_asset_stats` 和 `daily_node_traffic_stats` 回填状态表。
- 旧统计表继续保留，作为日维度事实来源和兼容数据。
