# Master 数据库版本 7

v7 为公开统计页面的批量查询补充索引，不改变既有表结构语义或业务数据。

## 结构变化

- 新增 `idx_node_availability_samples_window`，索引列为 `(sample_start, node_id)`，用于按时间窗口批量读取节点 SLA 样本。
- 新增 `idx_daily_node_traffic_stats_node`，索引列为 `(node_id, stat_day)`，用于按节点批量汇总公开下载流量。

## 升级规则

- 旧版本 `6` 主节点数据库打开时会在事务内创建上述索引并更新 `database_version`。
- 索引使用 `CREATE INDEX IF NOT EXISTS`，重复执行保持幂等。
