# 主节点数据库版本 1

版本 `1` 是主节点数据库结构的初始基线。空库启动时会一次性创建本版本结构；旧主节点库若没有 `database_version`，会被收编为版本 `1`。

## 结构范围

- 项目、Release、资产、公开路径和目标库存。
- 下载节点、节点证书、登记请求、配对码、控制会话、心跳和同步任务。
- 下载授权、流量事件、额度桶、日统计和 SLA 样本。
- 管理面板会话、用户安全状态、IP 封禁和审计日志。
- 公开探测状态、项目扫描状态、节点项目分配和同步任务租约。

## 收编旧库

旧主节点库没有 `database_version` 时：

- 直接标记为主节点版本 `1`。
- 旧的 `schema_migrations` 表会被删除。

## 升级器

版本 `1` 没有上一级版本，因此没有 `v0 -> v1` 升级器。空库初始化直接应用主节点 v1 结构。
