# Master 数据库 v4

v4 为下载节点增加公开下载优先级。

## 结构变化

在 `nodes` 表新增：

- `download_priority INTEGER NOT NULL DEFAULT 50`：公开下载授权选节点时使用的优先级，范围 `0-100`，数值越大基础分越高。

该字段只影响用户下载授权绑定哪个可路由节点，不改变节点健康状态、同步目标生成、任务派发或 peer fallback 来源选择。授权选择会在优先级基础上扣减实时带宽压力和少量活动下载数；压力样本缺失或过旧时不惩罚节点。管理面板保存后立即影响后续新签发的下载授权；已签发令牌仍绑定原节点直到过期。

## 升级器

- `master.V3ToV4`：为旧版主节点数据库的 `nodes` 表增加 `download_priority` 列。

## 兼容风险

- 空主节点库会直接创建带该字段的版本 `4` 结构。
- 旧版本主节点数据库打开时会在事务内补齐 `nodes.download_priority`，既有节点默认值为 `50`。
