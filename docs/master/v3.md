# Master 数据库 v3

v3 为资产分类规则增加来源与展示元数据字段。

- `releases.source_type`、`releases.source_release_key`：记录版本来源类型和来源侧版本标识。
- `assets.source_type`、`assets.source_asset_key`：记录资产来源类型和来源侧资产标识。
- `assets.variant`、`assets.display_label`、`assets.priority`、`assets.labels_json`、`assets.classification_reason`：保存 master 扫描阶段的分类结果。

这些字段不改变下载节点同步协议；节点仍按资产 ID、公开路径、大小、下载 URL 和 SHA-256 摘要执行任务。
