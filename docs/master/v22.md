# Master 数据库版本 22

## 结构变化

- 新增 `historical_node_traffic_totals`，在节点被删除后永久保存该节点的累计发送流量和最后公开名称；该表不引用 `nodes`，因此节点实体删除不会带走历史统计。
- 新增 `historical_daily_node_traffic_stats`，保存已删除节点的逐日发送流量；同样不依赖 `nodes` 外键。
- 新增 `idx_historical_daily_node_traffic_day`，用于公开统计和管理后台按日期合并现存节点与历史节点流量。

## 行为变化

- 删除节点时，在同一事务中先归档 `node_traffic_totals` 与 `daily_node_traffic_stats`，再清理节点运行态数据。
- 总流量与逐日流量按“现存节点 + 已删除节点历史”汇总，并继续与旧版 `public_stat_totals` / `daily_public_stats` 取较大值，以兼容历史版本曾发生的项目重置统计回退。
- 本升级不会自动猜测或重建升级前已经删除节点的流量；缺失历史需依据生产归档或已知数据单独修复。

## 升级器

- `internal/storage/upgrades/master.V21ToV22`。
- 升级仅新增历史流量表和索引，不修改现有节点或流量数据。
