# 主节点数据库版本 2

版本 `2` 为管理登录封禁增加后台展示 IP 字段。

## 结构变化

在 `admin_ip_blocks` 表新增：

- `display_ip TEXT NOT NULL DEFAULT ''`：记录管理登录封禁列表用于展示的来源 IP。`ip_key` 仍作为哈希匹配键，解除封禁仍使用该键。

旧记录无法从哈希反推完整 IP，升级后该字段保持为空，后台列表会回退显示旧的脱敏 IP。

## 升级器

- `master.V1ToV2`：为旧版主节点数据库的 `admin_ip_blocks` 增加 `display_ip` 列。

## 兼容风险

- 空主节点库会直接创建带该字段的版本 `2` 结构。
- 旧版本 `1` 主节点数据库打开时会在事务内补齐 `admin_ip_blocks.display_ip` 并更新 `database_version`。
