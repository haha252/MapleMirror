# Master 数据库 v15

## 结构变化

- 新增 `idx_target_inventory_asset_state_node`，用于按资产和目标状态重建目标库存。
- 新增 `idx_node_project_assignments_project_assigned_node`，用于按项目查找已分配节点。

## 升级器

- `master.V14ToV15`
- 升级时仅补充索引，不修改现有数据。

## 兼容风险

- 旧库升级会在线创建两个索引；表较大时启动阶段会有短暂额外 I/O。
- 索引创建完成后，项目目标重建和删除目标标记应减少全表扫描与重复相关子查询。

## 验证方式

- 空库启动应创建两个新增索引。
- 从 v14 旧库升级后，`database_version(master)` 应推进到 `15`。
- 项目扫描或项目发布后，`target_inventory` 的 required/remove 状态应保持与 v14 语义一致。
