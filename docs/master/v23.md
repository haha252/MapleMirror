# Master 数据库版本 23

## 结构变化

新增五个在线查询索引：

- `idx_download_authorizations_pending_delivery`：只索引可发送且尚未 ACK 的授权，按节点及发送顺序查询；避免每秒轮询扫描旧授权。
- `idx_target_inventory_required_counts`：只包含当前 required 库存，用于节点巡检汇总。
- `idx_node_inventory_live_counts`：覆盖 verified/mismatch 库存计数。
- `idx_node_tasks_live_counts`：覆盖未完成任务计数，跳过已完成历史。
- `idx_node_availability_rollups_counts`：覆盖节点及时间窗口的可用率汇总，减少回表。

## 升级器与兼容性

`internal/storage/upgrades/master.V22ToV23` 从版本 22 逐级升级，仅新增索引，不改变业务记录或清理策略。重复执行是幂等的。

启动时创建索引需要扫描已有记录；生产部署前应备份数据库，并预留升级时间。程序不支持自动降级；回滚旧程序时须使用升级前备份。

## 验证方式

- `go test ./internal/storage`：新建库、旧版本升级及查询计划。
- `go test ./internal/master/control ./internal/master/mirrorsync ./internal/master/public ./internal/master/adminui`：授权、库存、配置、巡检和管理会话行为。
