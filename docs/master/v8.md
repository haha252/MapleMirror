# Master 数据库版本 8

## 结构变化

- 新增 `traffic_event_dedupe`：以 `(node_id, event_sequence)` 保存流量事件幂等状态，只记录授权 ID、事件内容哈希和入账时间。
- 新增 `idx_traffic_event_dedupe_authorization`，用于按授权清理去重状态。
- 新增 `node_traffic_cursors`：保存每个节点最后接受的流量事件序号。
- 新增 `archive_migrations`：记录离线历史明细归档迁移的完成状态，供启动保护和后续维护命令使用。

## 升级器

- `internal/storage/upgrades/master.V7ToV8`

## 兼容风险

- 升级器只创建归档迁移所需结构，不在版本事务中导出或删除大体量历史明细。
- 新运行时流量事件不再写入 `traffic_events` 明细表，后续统计必须依赖 `daily_*` 聚合表、授权状态和流量预留状态。

## 验证方式

- `go test ./internal/storage`
- `go test ./internal/master/control`
