# 主节点数据库版本 12

v12 为公开统计页的热门资源排行补充项目级累计状态表，让榜单可以直接按项目维度读取全部启用项目的累计下载数据。

## 结构变化

- 新增 `project_stat_totals`，保存项目累计下载、Web/API 下载、开始传输和发送字节。
- 新增 `idx_project_stat_totals_downloads`，用于项目级热门排行排序。

## 升级行为

- `master.V11ToV12` 在事务内创建项目累计状态表和索引。
- 从 `daily_project_stats` 回填 `project_stat_totals`。
- 旧的 `daily_project_stats` 继续保留，作为日维度事实来源和兼容数据。
