# Master 数据库版本 20

## 结构变化

- 新增 `download_history`，按下载授权保存最近一段时间的人类可读排障快照。
- 每个授权只保存一行；Range、重试和多次流量事件会累计到同一行 `sent_bytes`。
- 保存 IP 主机前缀、项目/文件/版本、节点名称快照、签发与传输时间、状态和请求 ID。
- 历史表不保存原始下载 token，也不依赖项目、资产或节点外键，以便对象后续变更后历史仍可读。
- 新增 `(client_prefix_key, issued_at DESC)`、`issued_at` 和项目时间索引。

## 升级器

- `internal/storage/upgrades/master.V19ToV20`
- 升级时会尽力回填数据库中最近 7 天已有授权及已结算流量。

## 运行时

- 新授权签发时写入一条历史快照。
- 有效流量事件入账时同步累计 `sent_bytes` 并更新首次/最后传输时间。
- 授权状态事件同步更新历史状态和原因。
- 管理后台按 IP 查询该表；保留时间由 `history.download_retention_days` 控制，默认 7 天。
