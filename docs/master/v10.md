# Master 数据库版本 10

## 结构变化

- `download_authorizations` 新增 `source_kind`，记录下载授权来源，默认 `web`。
- `daily_project_stats` 和 `daily_asset_stats` 新增 `web_authorization_count`、`api_authorization_count`。

## 升级器

- `internal/storage/upgrades/master.V9ToV10`

## 数据迁移

- 既有日项目和日资产下载授权统计无法真实区分来源，升级时全部回填到 `web_authorization_count`。
- `api_authorization_count` 对历史数据保持 `0`。

## 兼容风险

- 总下载量 `authorization_count` 保持不变。
- 升级前历史 API 下载会按 Web 下载展示，这是公开统计口径的兼容选择。

## 验证方式

- `go test ./internal/storage`
- `go test ./internal/master/public`
