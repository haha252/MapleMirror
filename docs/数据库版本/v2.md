# 数据库版本 2

版本 `2` 为下载节点数据库增加库存强制上报标记，用于同步对账任务成功后立即触发下一次完整库存上报。

## 主节点

主节点数据库仍为版本 `1`，版本 `2` 不改变主节点结构。

## 下载节点

版本 `2` 在 `inventory_report_cursor` 表新增：

- `force_report_requested_at TEXT`：记录需要绕过 `inventoryReportMinInterval` 的完整库存上报请求时间。

该字段不改变 `next_revision` 或 `last_acked_revision`，只作为本地控制面判断“下一次完整库存是否立即到期”的触发标记。完整库存成功上报后会清除已消费的标记；若上报过程中又产生新的强制请求，则保留到下一轮。

## 升级器

- `upgradeNode1To2`：为旧版下载节点数据库的 `inventory_report_cursor` 增加 `force_report_requested_at` 列。

## 兼容风险

- 空库会直接创建带该字段的版本 `2` 下载节点结构。
- 旧版本 `1` 下载节点数据库打开时会在事务内补列并更新 `database_version`。
- 主节点数据库不需要升级。
