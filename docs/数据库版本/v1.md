# 数据库版本 1

版本 `1` 是当前数据库结构的初始基线。空库启动时会一次性创建本版本结构；旧库若没有 `database_version`，会被收编为版本 `1`。

## 主节点

版本 `1` 覆盖以下能力所需结构：

- 项目、Release、资产、公开路径和目标库存。
- 下载节点、节点证书、登记请求、配对码、控制会话、心跳和同步任务。
- 下载授权、流量事件、额度桶、日统计和 SLA 样本。
- 管理面板会话、用户安全状态、IP 封禁和审计日志。
- 公开探测状态、项目扫描状态、节点项目分配和同步任务租约。

## 下载节点

版本 `1` 覆盖以下本地结构：

- `local_assets`：本地已校验资产索引。镜像文件本体仍保存在文件系统，不进入数据库。
- `pending_traffic_events`：未被主节点确认的流量事件。
- `pending_sync_task_results` 和 `local_sync_tasks`：同步任务结果与本地运行状态。
- `control_identity`：节点 ID、证书指纹、证书到期时间、节点证书、节点私钥、主节点 CA 和下载令牌验证公钥。
- `node_enrollment_state`：配对码、登记请求 ID 和登记期间生成的临时私钥。
- `inventory_report_cursor` 和 `control_state`：库存上报和控制面本地游标。

## 收编旧库

旧库没有 `database_version` 时：

- 主节点库直接标记为版本 `1`。
- 下载节点库会补齐 `control_identity` 中的身份材料列和 `node_enrollment_state` 表。
- 旧的 `schema_migrations` 表会被删除。

## 升级器

版本 `1` 没有上一级版本，因此没有 `0 -> 1` 升级器。空库初始化直接应用 v1 结构。
