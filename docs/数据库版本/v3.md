# 数据库版本 3

版本 `3` 为下载节点数据库的同步任务结果队列保留 peer fallback 尝试标记，避免结果落盘后丢失重试语义。

## 主节点

主节点数据库仍为版本 `1`，版本 `3` 不改变主节点结构。

## 下载节点

版本 `3` 在 `pending_sync_task_results` 表新增：

- `peer_fallback_attempted INTEGER NOT NULL DEFAULT 0`：记录任务执行时是否已经尝试过 peer fallback。

该字段会随 `sync_task_result` 上报给主节点。主节点据此区分“源站失败但还没试过 peer”和“源站、peer 都失败”，避免已尝试 peer 的任务被误判为可以立即重派，从而绕过退避。

## 升级器

- `upgradeNode2To3`：为旧版下载节点数据库创建或补齐 `pending_sync_task_results.peer_fallback_attempted` 列。

## 兼容风险

- 空库会直接创建带该字段的版本 `3` 下载节点结构。
- 旧版本 `1` 或 `2` 下载节点数据库打开时会在事务内补齐该列并更新 `database_version`。
- 主节点数据库不需要升级。
