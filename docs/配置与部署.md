# 配置与部署

> 状态：当前交付版
> 需求基线：`docs/开发要求.md` 定稿 v1.1（2026-05-27）
> 文档说明：本文记录当前推荐配置合同、部署边界和兼容迁移要求。

## 1. 部署角色

首版部署由一个主节点和一个或多个下载节点组成。主节点集中负责公共页面、公开 API、验证、额度、授权、统计、管理面板、节点控制和 Release 同步；下载节点负责资产同步、SHA-256 校验、本地文件服务、Range 下载和真实流量事件补报。

| 角色 | 必需文件 |
| --- | --- |
| 主节点 | `config.yaml`、`projects.yaml`、`quota.yaml`、SQLite 主库、管理 TLS、节点控制 TLS、节点签发 CA、下载令牌 Ed25519 私钥和公钥 |
| 下载节点 | `node.yaml`、SQLite 本地状态库、资产目录、临时目录 |

## 2. 主节点配置

主节点启动命令读取三个配置文件：

```powershell
.\master.exe -config config.yaml -projects projects.yaml -quota quota.yaml
```

配置文件不存在时，程序会生成带中文注释的完整示例并安全退出。配置文件已存在时，启动加载会先把可安全转换的旧字段写回迁移为新字段，再自动补齐当前模板中缺失的配置项和对应注释；已有新字段不会被旧字段覆盖。补齐后仍按当前配置合同校验，缺少必填身份、仓库或密钥材料时会继续报错。

| 配置 | 关键字段 |
| --- | --- |
| `server.public_listen` | 公共页面和公开 API 监听地址 |
| `server.management_listen` | 管理监听地址，默认回环；可改为明确的管理网络监听 |
| `server.control_listen` | 下载节点 mTLS 控制通道 |
| `server.enrollment_listen` | 下载节点首次登记入口 |
| `database.path` | 主节点 SQLite 路径 |
| `database.busy_timeout`、`database.wal` | SQLite 并发等待和 WAL |
| `proxy.trusted_cidrs` | 允许解析代理头的直连代理 CIDR |
| `stats.timezone` | 日统计和日限额时区，默认 `Asia/Shanghai` |
| `scan.interval`、`scan.github_token_env` | 单项目 Release 自动扫描间隔和 GitHub Token 环境变量名 |
| `altcha.difficulty`、`altcha.challenge_ttl` | 网页挑战前导零位难度和挑战有效期，默认难度 `22` |
| `api_pow.*` | 公开 API SHA-256 前导零 PoW 参数 |
| `download_token.ttl`、`download_token.signing_private_key_file`、`download_token.verify_public_key_file` | 下载令牌有效期、Ed25519 签发私钥和验证公钥 |
| `node.*` | 心跳、登记、配对码、节点 TLS、控制/登记服务端 CA 和节点签发 CA |
| `node.public_probe_*` | 下载节点公网 HTTP 入口防伪探测；默认启用，间隔 `60s`，网络类失败连续 `5` 次暂停公开下载路由但不标记控制面离线，回答字段或签名错误单次离线 |
| `admin.*` | 管理面板登录、会话、防爆破和 HTTPS 服务端证书 |

管理监听器只提供 Web 管理面板，不再对外挂载裸 `/api/admin/v1/*` 管理接口。访问管理监听根路径 `/` 会跳转到 `/admin/`，未登录时进入 `/admin/login`。浏览器登录后只调用同源 `/admin/api/*` 完成管理操作。

```yaml
admin:
  web:
    https_enabled: true
    users_file: "secrets/admin-users.yaml"
    bootstrap_password_env: "MIRROR_ADMIN_WEB_PASSWORD"
    session_secret_file: "secrets/admin-web-session.key"
    session_ttl: "12h"
    login_failure_window: "24h"
    login_failure_limit: 3
    login_ban_duration: "168h"
  tls:
    cert_file: "secrets/admin-web.crt"
    key_file: "secrets/admin-web.key"
```

管理面板启用且 `admin.web.users_file` 不存在时会自动创建初始用户文件。若 `admin.web.bootstrap_password_env` 指向的环境变量存在且有值，初始用户为 `admin`，密码取环境变量；否则生成 8 位随机用户名和 20 位随机密码，明文只输出到启动控制台一次，不写入日志文件或用户文件。

`scan.interval` 表示每个启用项目各自的自动扫描间隔。主节点会在 SQLite `project_scan_state` 中记录每个项目的上次扫描和 `next_scan_at`，后台调度只扫描已到期项目；`projects.yaml` 新增项目或项目配置摘要变化时，该项目会被设置为尽快扫描。该字段不再表示把全部启用项目集中到同一个全局批量扫描 tick。

`quota.yaml` 的 `authorization_max_bytes_multiplier` 控制单个下载授权最多可发送字节数：`max_bytes = 资产大小 * 倍数`，默认 `2`。每日流量限制采用事后限流：主节点签发授权时只检查当天已经幂等入账的真实发送字节，未使用或未结算的授权预留不参与限流判断；下载节点按已实际发送并记录的响应体字节判断授权是否已耗尽，不按客户端声明的 Range 范围预扣。`range_concurrency_limit` 控制单个授权可同时存在的 Range 请求数，默认 `32`。主节点不会远程中断下载节点上已经运行的 HTTP 处理；但新签发的下载令牌会携带按真实剩余额度收窄后的可发送上限，下载节点在响应体写到该上限时立即停止继续发送。

`quota.yaml` 的 `blocklist.static` 可配置静态恶意客户端 IP 或 CIDR；`blocklist.feeds` 可配置 HTTP/HTTPS 远程订阅源，例如公共恶意 IP 列表。订阅源按 `refresh_interval` 后台刷新，单次拉取受 `timeout` 和最大响应大小限制；刷新失败时继续使用上一次成功快照并写中文告警，不阻断主节点启动或下载服务。`exemptions` 优先于黑名单，用于本机、监控和明确可信地址。命中黑名单的客户端会在挑战创建和授权签发前被拒绝，日志包含 `block_reason`、`block_source` 和 `blocked_after_attempts`，用于判断“封禁后仍尝试下载”的次数。

本站自动封禁持久化在主库 `client_blocks` 表中，只记录本下载站因 `REQUEST_QUOTA_EXHAUSTED` 或 `TRAFFIC_LIMIT_EXCEEDED` 写入的封禁。`blocklist.auto_ban_duration` 控制默认过期时间，默认 `168h`，也就是 7 天；后续管理面板可通过延长 `expires_at` 调整更长封禁。订阅源黑名单不写入该表，只要客户端 IP/CIDR 仍在订阅源当前快照中就继续封禁，移出列表后随下一次成功刷新解除。

当前黑名单边界位于主节点公开下载链路。主节点不签发下载令牌时，正常浏览器和公开 API 客户端无法下载；下载节点侧黑名单同步只作为旧令牌有效期、错误反代或未来多入口漂移的兜底项。

### 2.1 `projects.yaml` 项目图标

`projects.yaml` 的 `projects[]` 可选字段 `icon_path` 用于配置下载页项目图标，要求如下：

- 路径相对当前 `projects.yaml` 所在目录，例如 `project-icons/foldcraftlauncher.svg`。
- 只允许 `png`、`jpg`、`jpeg`、`gif`、`webp`、`svg`。
- 不允许绝对路径、空白路径或 `..` 越级路径。
- 主节点通过 `/static/project-icons/{project_id}` 对外提供图标；文件缺失时回退内置占位图标并写中文告警。

随仓库示例一起提供了 `configs/project-icons/example.svg`，构建脚本会把 `configs/` 连同示例图标一起复制到发布目录。

## 3. 下载节点配置

下载节点启动命令：

```powershell
.\node.exe -config node.yaml
```

| 配置 | 关键字段 |
| --- | --- |
| `node.name` | 公开可展示节点名 |
| `server.listen` | 下载节点 HTTP 文件服务和健康检查监听 |
| `server.public_download_base_url` | 浏览器和 API 客户端直连下载节点时使用的公网基地址；生产应使用 HTTPS origin，HTTP 仅允许本机回环调试 |
| `master.control_address` | 主节点 mTLS 控制入口 HTTPS 地址 |
| `master.enrollment_address` | 首次登记入口 HTTPS 地址 |
| `storage.directory` | 已验证资产目录 |
| `storage.temp_directory` | 同步临时文件目录 |
| `storage.state_db` | 下载节点 SQLite 状态库；持久化节点身份材料、登记临时状态、同步状态和未确认流量事件 |
| `bandwidth.target` | 目标出口带宽，支持 `MiB/s`、`MB/s`、`Mbps`，节点心跳和压力报告会上报 `target_bandwidth_bps` |
| `sync.max_workers` | 同步任务并发上限，节点侧按该值限制同时执行的同步任务数 |
| `sync.max_mirror_projects` | 本节点最多承接的镜像项目数，`0` 表示不限制；主节点按最近 30 天下载量自动分配，自动换项需满足 3 天保留和 20% 热度差 |
| `sync.bandwidth_limit` | 单个同步下载限速，支持 `MiB/s`、`MB/s`、`Mbps`，`0` 表示不限速 |
| `download_token.verify_public_key_file` | 旧版本下载令牌 Ed25519 验证公钥文件；启动时会导入 `storage.state_db` |
| `proxy.trusted_cidrs` | 下载节点位于反向代理后时，允许解析代理头的直连代理 CIDR |
| `pairing.code_file`、`pairing.credential_file` | 非交互登记输入和旧版本凭据导入；新登记临时状态写入 `storage.state_db` |
| `tls.*` | 旧版本主节点 CA、节点证书、节点私钥导入路径，以及服务端名称 |

下载节点未完成登记或 `storage.state_db` 中身份材料缺失时，不得启动控制连接；无法加载下载令牌验证公钥或节点身份时，不得启动文件服务。`server.public_download_base_url` 必须是浏览器可访问的 HTTPS origin，不得包含用户名、密码、路径、查询或片段；HTTP 仅允许 `localhost`/回环地址调试。主节点只接受规范化后的可信基址，并拼成最终 `download_url` 返回给客户端。

## 4. 首次交互初始化

主节点首次启动若发现配置或安全材料缺失，会在交互式终端提示生成初始化材料；无交互终端时必须退出并输出中文修复指引，不得阻塞等待输入。初始化会生成下载令牌 Ed25519 keypair、`node.tls.ca_file/ca_key_file` 控制/登记服务端 CA、控制/登记 TLS 服务端证书、节点签发 CA 和管理面板 HTTPS 服务端证书。管理面板用户文件在首次启动面板时按 `admin.web.users_file` 与 `admin.web.bootstrap_password_env` 自动创建。

下载节点首次启动若尚无节点身份，会在交互式终端询问节点名、主节点登记/控制地址、TLS 服务端名称和一次性配对码。节点首次连接登记入口时展示主节点 TLS 证书指纹，人工确认后提交 CSR；审批通过后把节点证书、节点私钥、主节点 CA 链和下载令牌验证公钥保存到 `storage.state_db`。交互式重新配置或重新登记会清理旧本地身份、同步状态、待上报事件和本地资产目录，再使用新的配对码登记。

## 5. 反向代理与网络边界

| 入口 | 推荐暴露范围 | 说明 |
| --- | --- | --- |
| 主节点公共入口 | 公网 | 只转发公共页面和 `/api/public/v1/*` |
| 下载节点文件入口 | 公网 | 只转发 `/{project_id}/{version}/{file_name}`、兼容 `/downloads/{asset_id}`、`/.well-known/mirror-node/probes/{challenge_id}` 和健康检查 |
| 主节点管理入口 | 回环或管理网络 | 不得通过公共域名暴露；所有管理操作必须通过 Web 面板登录会话完成 |
| 主节点控制入口 | 节点网络 | 仅允许下载节点 mTLS |
| 主节点登记入口 | 节点接入网络 | 仅用于首次配对和证书领取 |

只有直连来源属于 `proxy.trusted_cidrs` 时，主节点或下载节点才可信任代理头解析真实客户端 IP；否则必须使用 TCP 对端地址。管理面板的登录封禁和会话绑定也使用同一规则。

管理入口放在可信 nginx 后时，nginx 至少应转发以下头：

```nginx
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-Proto $scheme;
```

同时把 nginx 与主节点直连的地址或网段加入 `proxy.trusted_cidrs`，用于 Web 管理面板的登录封禁和会话绑定识别真实来源。不要把公共入口代理到管理监听器。

## 5.1 公共前端资源

- 公共页面前端资源位于 `web/public/`，按 `templates/` 与 `static/` 拆分，并通过 Go `embed` 打包进主节点二进制。
- `scripts/build-windows.sh` 和 `scripts/build-linux-amd64.sh` 只复制示例配置到 `dist/*`；公共页面不再依赖外置 `web/` 目录。
- 若构建环境存在 `clang` 或 `zig`，脚本会把 `web/wasm/pow.c` 编译为 `web/public/static/pow.wasm`，浏览器下载验证优先使用多 Worker WASM 求解。页面只下载一次 WASM 字节，再分发给 Worker 并行实例化；缺少 WASM C 工具链时自动使用 JS 回退。
- 下载页支持浅色/深色模式。默认跟随 `prefers-color-scheme`，用户手动切换后由浏览器 `localStorage` 记住。
- 下载页采用项目卡片布局：项目图标、最近更新时间、版本选择器、文件信息和右下角下载按钮均由主节点页面提供。项目启用 `architecture_match_enabled` 后显示架构选择器；启用 `system_match_enabled` 后额外显示系统选择器。

## 5.2 资产规则与展示字段提取

`projects.yaml` 中每个项目只用 `asset_include` 和 `asset_exclude` 决定资产是否进入镜像。`architecture_regex` 和 `system_regex` 只负责从已入选资产文件名中提取下载页展示字段，提取失败不再拒绝资产；对应匹配开关未启用时不会识别该字段。

资产规则支持旧字符串写法和对象写法。旧字符串等同于 `type: glob`、`required: false`，用于兼容已有配置：

```yaml
asset_include:
  - "*.apk"
```

推荐使用对象写法，便于明确规则类型和必选关系：

```yaml
asset_include:
  - pattern: "\\.apk$"
    type: regex
    required: false
asset_exclude:
  - pattern: "(?i)(debug|source|unsigned)"
    type: regex
    required: false
```

规则字段说明：

- `pattern`：匹配资产文件名的字符串，不能为空。
- `type`：`glob` 或 `regex`。`glob` 支持 `*.apk`、`*.zip`；`regex` 使用 Go 正则，可写 `(?i)` 做大小写不敏感匹配。
- `required`：是否为必选规则。`asset_include` 中所有 `required: true` 都必须命中；如果存在 `required: false`，还必须至少命中一条可选规则。没有 `asset_include` 时默认允许所有资产进入下一步。
- `asset_exclude` 优先于 `asset_include`。任意 `required: false` 排除规则命中就拒绝资产；`required: true` 排除规则用于组合排除，只有全部必选排除规则都命中时才拒绝资产。

默认不区分架构，资产响应中的 `architecture` 字段为空字符串，下载页不显示架构选择器。需要把 amd64、arm64、x86 等资产分开展示时，可在项目内开启：

```yaml
architecture_match_enabled: true
architecture_regex: "(?i)(amd64|arm64|x86_64)"
```

开启后，扫描会从文件名中提取展示架构；未命中时 `architecture` 写入 `None`，资产仍会进入候选。

默认不区分系统，资产响应中的 `system` 字段为空字符串。需要把 Windows、Linux、macOS 等资产分开展示时，可在项目内开启：

```yaml
system_match_enabled: true
system_regex: "(?i)(windows|win|linux|darwin|macos|osx)"
```

开启后，扫描会从文件名中提取系统并规范化为 `win`、`linux` 或 `darwin`；无法匹配或无法规范化时 `system` 写入 `None`，资产仍会进入候选。下载页在系统和架构都开启时按“版本 -> 系统 -> 架构”筛选；只开启系统时按“版本 -> 系统”筛选；只开启架构时按“版本 -> 架构”筛选。

## 6. 证书和密钥

| 材料 | 规则 |
| --- | --- |
| 管理面板 HTTPS 证书 | 管理面板传输保护，`admin.web.https_enabled=true` 时启动必需 |
| 控制/登记服务端 CA | `node.tls.ca_file/ca_key_file`，用于签发控制和登记入口服务端证书；CA 证书会下发给下载节点，CA 私钥只留在主节点 |
| 节点控制服务端证书 | 登记和控制入口 TLS 1.3 服务端身份 |
| 节点客户端证书 | 下载节点控制连接 mTLS 身份 |
| 节点签发 CA | 主节点签发节点客户端证书，私钥不得进入日志 |
| 下载令牌签发私钥 | 仅主节点保存 Ed25519 私钥，用于签发下载令牌和网页挑战兼容签名 |
| 下载令牌验证公钥 | 下载节点只在 `storage.state_db` 保存 Ed25519 公钥，用于验证下载令牌，不具备伪造令牌能力 |

证书过期、轮换或吊销后，旧控制会话必须关闭；节点重新连接后仍需确认同步状态和未确认事件补报。

## 6.1 旧配置键兼容迁移

旧配置键只作为兼容输入存在，不再出现在示例主路径和管理面板保存结果中。

| 旧字段 | 当前字段 | 启动行为 |
| --- | --- | --- |
| `quota.blacklist` | `quota.blocklist.static` | loader 写回迁移到 `blocklist.static`，去重保留已有新字段项，并写中文弃用警告 |
| `projects[].architecture_default_enabled` | `projects[].architecture_match_enabled` | loader 在新字段缺失时写回迁移为 `architecture_match_enabled`；新字段已存在时删除旧字段但不覆盖新字段，并写中文弃用警告 |
| `download_token.signing_key_file` | 主节点 `download_token.signing_private_key_file` 加 `download_token.verify_public_key_file`，下载节点只保留 `download_token.verify_public_key_file` | 启动时报中文迁移错误，不恢复旧 HMAC 令牌逻辑 |

## 7. SQLite 备份

### 7.1 主节点备份

备份内容：

- `database.path` 指向的 SQLite 文件。
- 启用 WAL 时的 `-wal`、`-shm` 文件，或 checkpoint 后的一致主库。
- `config.yaml`、`projects.yaml`、`quota.yaml`。
- 管理面板 HTTPS、控制/登记服务端 CA、节点 TLS、节点签发 CA、下载令牌 Ed25519 私钥和公钥。
- 最近日志，排除敏感明文。

### 7.2 下载节点备份

备份内容：

- `storage.state_db`。
- `storage.directory` 已验证资产。
- 未确认流量事件和同步任务状态。
- `node.yaml`。

恢复后必须先启动主节点，再逐个启动下载节点，等待节点补报流量事件和重新对账，确认后才能恢复公共路由。

## 8. 迁移失败恢复

1. 升级前必须保存迁移前备份，并记录当前 Git 提交和 `database_version`。
2. 迁移失败后立即停止服务，保留失败数据库副本和日志。
3. 不得直接编辑 `database_version` 或手工删除升级痕迹。
4. 使用迁移前备份恢复，回滚二进制和配置。
5. 恢复后运行只读检查，确认授权、额度、流量事件和节点状态可查询。

## 9. 日志与编码

- 日志、配置、文档和脚本统一 UTF-8。
- Windows PowerShell 读取中文文件必须使用 `Get-Content -Encoding UTF8`。
- 日志不得记录管理面板密码、会话 Cookie、下载令牌、配对码明文、下载令牌私钥、证书私钥、完整客户端 IP、完整 URL 查询令牌或本地绝对路径。
- 一次性配对码完整值只允许打印到当前交互控制台；普通日志只能记录配对记录 ID、短前缀和过期时间。
- 可记录请求 ID、任务 ID、截断授权 ID、节点 ID、资产 ID、稳定错误码和中文摘要。

## 10. 启停检查

### 10.1 主节点启动后

- 公共健康检查返回正常。
- 管理面板只在管理监听可访问，裸 `/api/admin/v1/*` 不可访问。
- 控制面和登记入口使用 TLS 1.3。
- Release 扫描调度启动。
- 公共页面和公开 API 返回中文错误与 `X-Request-ID`。
- SLA 采样任务不阻塞公共请求。

### 10.2 下载节点启动后

- 健康检查返回正常。
- 已登记节点建立 mTLS 控制连接。
- 未确认 `pending_traffic_events` 自动补报。
- 文件服务只在节点身份和签名密钥可用后启动。
- `/{project_id}/{version}/{file_name}` 校验令牌、资产、节点、客户端前缀和 Range；兼容 `/downloads/{asset_id}`。
