# 前端兼容性

## 支持边界

前台页面、管理面板和网页下载验证以 Chromium / Android System WebView 67 为最低功能基线。Android 9 设备应将 System WebView 更新到至少该版本。内核低于该基线时，普通页面可能仍能阅读，但不保证下载流程可用。

下载 PoW V2 使用 3072 位整数做重复模平方，因此必须具备原生 `BigInt`。这是完整下载流程的硬下限，不会为更早的内核引入大整数仿真库。

## 降级策略

| 能力 | 现代浏览器 | 兼容路径 |
| --- | --- | --- |
| DOM 内容替换 | `replaceChildren` | 先删除子节点，再逐个追加 |
| 媒体查询变化 | `addEventListener("change")` | 回退到 `addListener` |
| 请求取消 | `AbortController` | 保留请求序号隔离，不传递 `signal` |
| 目录触底加载 | `IntersectionObserver` | 显示“加载更多”按钮 |
| 瀑布流重排 | `ResizeObserver` | 保留 CSS Grid 排版 |
| VDF 计算 | Web Worker | Worker 失败或缺失时在主线程分批计算并持续更新进度 |

降级只改变实现路径，不改变页面结构、交互文案、响应式断点和现代浏览器样式。

## 验收清单

1. 首页能请求目录、渲染项目卡片、搜索并分批加载。
2. 项目详情页能切换条件选择和文件选择。
3. 下载页能创建 V2 挑战、计算 384 字节定长结果、提交授权并带令牌跳转。
4. Worker 被禁用时，第 3 项仍能通过主线程分批计算完成。
5. 惩罚 PoW 的 Worker + WASM 路径失败时，仍会回退到单线程 Web Crypto。
