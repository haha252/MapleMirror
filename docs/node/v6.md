# 下载节点数据库 v6

## 结构变化

- `local_sync_tasks` 与 `pending_sync_task_results` 增加 `attempt_id`。
- 新增 `swarm_partials`，持久化 partial 路径、manifest 绑定和 verified piece bitmap。
- 不按 piece 建行，避免高频 SQLite 写放大。

## 升级器

- `node.V5ToV6`。
- 对缺少可选历史表的最小化旧库安全跳过相关列迁移。

## 验证方式

- `go test ./internal/storage`
- `go test ./internal/node/control ./internal/node/syncer`

- 新增 `pending_swarm_manifests` durable outbox，保证 seed 完成 whole-file 校验后即使 WSS 在 Manifest ACK 前断开，重连仍可重报 Manifest；只有 Manifest ACK 被持久处理后才进入 `sync.result` durable outbox。
