# 2026-10-04 SQL 日志排查

## 证据范围

来自生产主节点 `master-2026-10-04.log` 的用户提供统计，共 1,433,040 条 SQL 执行日志，格式异常行数为 0。统计截止于采集时刻，不代表完整 24 小时。

SQL 耗时由驱动记录，不包含连接池等待及日志写入。累计耗时是各调用耗时之和，不等于数据库占用的墙钟时间；日志 SQL 文本可能截断，统计不能直接证明每一条连接超时的原因。

16:16:13 峰值为每秒 5,702 条 SQL 执行日志。多个节点库存片段同时处理，叠加主数据库单连接串行执行，具有排队放大的条件；修复效果仍需部署后的同口径日志验证。

| 路径 | 日志结果 | 优化 |

## 生产复查

在有本仓库脚本的主机上，只读扫描当前日志目录：

```bash

```
